# SKILLS.md の作成・編集・管理・最適化ガイド

本ドキュメントは、AI アシスタント用の `SKILLS.md` を作成、維持、最適化するためのベストプラクティスをまとめています。

---

## 1. SKILLS.md の基本構造

Antigravity のスキルは `.agents/skills/<skill-name>/SKILL.md` に配置します。

```markdown
---
name: skill-name
description: >-
  このスキルがいつ・どのように利用されるべきかの説明（モデルが呼び出し判断に使用する）。
---

# スキルタイトル

スキルの概要と目的

## 手順・ガイドライン
1. Step 1...
2. Step 2...
```

---

## 2. スキル最適化のチェックリスト

- [ ] **明確な description**: モデルが適切なタイミングでスキルを選択できるよう、適用条件と目的を具象的に記述する。
- [ ] **成果物の明確化**: 各フェーズで作成・出力すべきドキュメントやファイルのパス（例: `docs/requirements.md`）を指定する。
- [ ] **構造化とテンプレート化**: Markdown のテンプレート例や Mermaid ダイアグラムを提示する。
- [ ] **検証ステップの明記**: 実装やテスト、デプロイなどの動作フェーズでは、具体的な実行コマンド（`npm test` や `docker build` など）を記載する。
