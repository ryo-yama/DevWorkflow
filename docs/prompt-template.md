# 🚀 開発開始用 プロンプトテンプレート

このドキュメントは、自分が作りたいアプリケーションやシステムのアイデアを AI アシスタントへ入力する際に使用する**最適化プロンプトテンプレート**です。

---

## 📋 コピペ用プロンプトテンプレート

以下のテンプレートをコピーし、`【 】` 内を埋めて AI に送信してください。未決定の項目は空欄のままでも構いません。

```markdown
`full-stack-workflow` スキルに従って、以下のアイデアから開発フロー（要件定義→仕様作成→設計→実装→テスト→デプロイ）を開始してください。

■ 作りたいものの概要:
【例: 個人開発者向けのタスク・習慣管理ダッシュボード】

■ 解決したい課題 / 背景:
【例: 既存のタスク管理アプリは機能が多く複雑なため、シンプルに日々の習慣化とタスク完了率を視覚化したい。】

■ ターゲットユーザー:
【例: シンプルなツールを好む個人開発者・フリーランス】

■ 希望する技術スタック / 開発環境 (任意):
- フロントエンド: 【例: Next.js (TypeScript) / Tailwind CSS】
- バックエンド: 【例: Node.js (FastAPI or Next.js API Routes)】
- データベース: 【例: PostgreSQL (Supabase) / SQLite】
- 運用・デプロイ環境: 【例: Vercel / Docker】

■ その他こだわり・制約条件 (任意):
【例: モバイル表示に対応させたい、ダークモードを初期対応したいなど】

まず最初は、ステップ1の「要件定義 (requirements-definition)」から進めてください。不足している情報やヒアリング事項があれば質問してください。
```

---

## 💡 入力例（具体例）

### 例1: シンプルなWebアプリ（ToDo / タスク管理）
```markdown
`full-stack-workflow` スキルに従って、以下のアイデアから開発フローを開始してください。

■ 作りたいものの概要:
リアルタイムで共同編集できる簡易ホワイトボードWebアプリ

■ 解決したい課題 / 背景:
リモート会議中にチームで手軽にアイデア出しやブレストを行いたい。

■ ターゲットユーザー:
リモートワークを行っている小規模チーム・エンジニア

■ 希望する技術スタック / 開発環境 (任意):
- フロントエンド: React, TypeScript, HTML Canvas
- バックエンド: Node.js, WebSocket (Socket.io)
- データベース: なし（インメモリ処理）

まずはステップ1の「要件定義」から進めてください。
```

### 例2: CLIツール / 自動化スクリプト
```markdown
`full-stack-workflow` スキルに従って、以下のアイデアから開発フローを開始してください。

■ 作りたいものの概要:
Gitリポジトリのコミットログからリリースノートを自動生成するCLIツール

■ 解決したい課題 / 背景:
リリース作業時のチェンジログ作成の手間を削減したい。

■ ターゲットユーザー:
開発者・DevOps担当者

■ 希望する技術スタック / 開発環境 (任意):
- 言語: Python または Rust

まずはステップ1の「要件定義」から進めてください。
```
