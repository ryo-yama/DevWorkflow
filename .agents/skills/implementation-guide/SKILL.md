# 実装ガイドスキル (Implementation Guide Skill)

このスキルは、設計フェーズで決定された構成に基づき、正確・安全かつ効率的にコードを実装するためのベストプラクティスを提供します。

---

## 開発・実装の原則

1. **段階的実装 (Iterative Implementation)**:
   一度に巨大な変更を加えずに、コンポーネント・モジュール単位で小さく実装および動作確認を行う。
2. **型安全性の徹底**:
   TypeScript や Python Type Hint などを最大限活用し、`any` や型なしコードの乱用を避ける。
3. **安全なエラーハンドリング**:
   例外の無駄な握りつぶしやダミーのフォールバックを避け、明確なログとエラーメッセージを生成する。
4. **GEMINI.md ルールの遵守**:
   プロジェクトの `GEMINI.md` に記載されているコーディング規約・ビルド方法・リント設定に従う。

---

## 実装手順 (Implementation Steps)

### Step 1: プロジェクト基盤・型定義の構築
- データモデルおよび API インターフェースの型・Enum・Interface を定義する。

### Step 2: コアロジック・サービスの作成
- ビジネスロジックをサービス層/ユーティリティ層として実装する。

### Step 3: API エンドポイント / 入出力インターフェースの接続
- ルーティング、コントローラー、リクエストバリデーションの実装を行う。

### Step 4: 動作検証と型チェック
- コマンド（`npm run lint`, `tsc --noEmit`, `python -m mypy .` 等）を実行し、構文・型エラーが発生しないことを確認する。
