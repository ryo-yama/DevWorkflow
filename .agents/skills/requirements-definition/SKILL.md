# 要件定義スキル (Requirements Definition Skill)

このスキルは、プロジェクトの初期段階において、ユーザーの要望やアイデアを明確かつ網羅的な「要件定義」に集約・整理するためのガイドラインを提供します。

---

## 実施ステップ

### 1. アイデア・背景のヒアリングと分析
- **プロジェクトの目的・背景**: なぜこれを作るのか？どのような課題を解決するのか？
- **ターゲットユーザー**: 誰が使うのか？（ペルソナの設定）
- **主要な価値提案 (Value Proposition)**: 最も重要な機能・体験は何か？

### 2. 機能要件 (Functional Requirements) の策定
機能要件を優先度（Must / Should / Could / Won't）に分類して定義します。

- **コア機能 (Must)**: MVP（最小限のプロダクト）に必要な必須機能
- **追加機能 (Should/Could)**: 次のステップや将来拡張で導入する機能

### 3. 非機能要件 (Non-Functional Requirements) の定義
- **パフォーマンス**: 応答速度、処理能力など
- **セキュリティ**: 認証・認可、暗号化、データ保護
- **拡張性・保守性**: コード構造、モジュール性
- **対応環境・動作条件**: OS、ブラウザ、ハードウェア要件など

### 4. ユースケース / ユーザーシナリオの整理
主要な操作フローをユーザー視点で記述します。
